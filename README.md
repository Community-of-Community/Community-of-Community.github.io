# Community of Community — Project Page

**Make friends and Shared possibilities.**

This public repository hosts the bilingual project website for Community of Community (CoC). The introduction, founding members, community Issues, and Discussions live in the [main repository](https://github.com/Community-of-Community/Community-of-Community).

- **Website:** https://community-of-community.github.io/
- **Issues:** https://github.com/Community-of-Community/Community-of-Community/issues
- **Discussions:** https://github.com/Community-of-Community/Community-of-Community/discussions

## Preview and deployment

The site is plain HTML, CSS, and JavaScript; no build dependencies are required. Preview from this repository with `python3 -m http.server 8000 --bind 127.0.0.1`, then open http://127.0.0.1:8000/.

GitHub Pages publishes the repository root from `main` (`/`). The entry point is `index.html`; `.nojekyll` keeps deployment static.

## Collaboration form

The folded form sends introductions to `wayneyjin@gmail.com` through FormSubmit, with or without JavaScript. The recipient must activate it using FormSubmit's confirmation email on first use (check spam). If AJAX does not trigger activation, submit once with JavaScript disabled, confirm by email, and then test delivery again. An accepted request does not confirm email delivery. Never submit confidential information.
